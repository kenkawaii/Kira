# Kira Analytics - Website

A complete, responsive website for Kira Analytics, a predictive analytics SaaS platform for Malaysian F&B SMEs.

## 🎯 Project Overview

**Kira** helps F&B business owners in Malaysia make better decisions by:
- Forecasting demand for products
- Predicting customer churn
- Detecting anomalies in transaction data
- Providing plain-language explanations for all predictions

## 📁 Website Structure

```
/kira
├── index.html              # Home page (hero, product overview)
├── how-it-works.html       # 3-step process explanation
├── features.html           # Three core features showcase
├── comparison.html         # Kira vs other tools
├── faq.html               # Frequently asked questions
├── why.html               # Problem & opportunity
├── waitlist.html          # Email signup form
├── success.html           # Waitlist confirmation
└── README.md              # This file
```

## 🔗 Navigation Structure

All pages are fully linked with:
- **Top Navigation Bar** - Present on all pages
  - Logo links to home
  - Links to: How It Works, Features, FAQ
  - Sign In, Join Waitlist buttons

- **Footer** - Consistent across all pages
  - Product links (How It Works, Features, FAQ, Waitlist)
  - Learn links (Why Kira, Comparison)
  - Legal links (Privacy Policy, Terms, PDPA)
  - Copyright and email

## 📄 Page Descriptions

### Home (index.html)
- **Hero section** with headline "Kira your business one week ahead"
- **Product mockup** showing revenue forecast interface
- **CTA buttons** to join waitlist or learn more
- **Value proposition** text

### How It Works (how-it-works.html)
Three-step process:
1. Connect your data (CSV upload)
2. Kira learns your business (ML training)
3. Get answers, not dashboards (weekly summaries)

### Features (features.html)
Detailed showcase of three capabilities:
1. **Demand Forecasting** - Per-SKU predictions with confidence intervals
2. **Customer Churn Alerts** - Personalized at-risk customer identification
3. **Anomaly Detection** - Unusual transaction flagging

### Comparison (comparison.html)
Side-by-side comparison:
- **Other tools**: "Sales likely to drop next week"
- **Kira**: Full explanation + specific reasons + suggested actions

### FAQ (faq.html)
8 accordion questions covering:
- Accounting software compatibility
- Data security & PDPA compliance
- Forecast accuracy
- Technical requirements
- Free trial terms
- Beta access timeline
- Supported systems

### Why Kira (why.html)
Business case explaining:
- The problem: e-invoicing solved compliance but not forecasting
- The opportunity: Jan/July 2026 compliance deadlines
- Market size: RM1M-5M SMEs, 47M tourists expected
- Why now: Structured data + visible pain + no existing solutions

### Waitlist (waitlist.html)
Modal form collecting:
- Email address (required)
- Business name (required)
- Business type (required dropdown)
- Interview opt-in (checkbox)
- Form validation and redirect to success page

### Success (success.html)
Confirmation page after waitlist signup
